무료 로컬 AI

연결 전

AI 모델을 이 기기에 내려받아 브라우저에서 실행해. 유료 API 키는 필요 없어. 첫 다운로드는 수백 MB 이상일 수 있고, Safari/WebGPU 지원 여부와 기기 메모리에 따라 실행되지 않을 수도 있어.

모델을 불러오면 실제 AI 답변 생성과 답변 재생성이 활성화돼.
AI 답변은 선택한 캐릭터, 유저 프로필, 세계관 문서, 최근 대화를 참고해 생성돼. 데이터는 이 브라우저에 저장되며, 모델 다운로드를 위해 모델 파일 제공 서버에 연결해.
AI 모델이 준비되면 실제 답변을 생성해. 모델이 준비되지 않았다면 메시지는 저장하지 않고 안내해.

백업과 복원

인물, 유저 설정, 세계관 문서, 대화방을 JSON 파일로 내보내거나 다시 가져올 수 있어.

무료 AI 연결 안내

이 파일에는 유료 API 키가 포함되어 있지 않아. AI 응답 생성 기능을 실제로 쓰려면 브라우저에서 직접 실행되는 호환 모델을 연결해야 해. 아이폰 Safari에서는 모델 다운로드 용량, 메모리, WebGPU 지원에 따라 실행이 느리거나 실패할 수 있어.

대화 재생성·메시지 수정 UI는 포함되어 있어. 모델을 연결하기 전에는 실제 AI가 답변을 생성하지 않아.

모든 데이터 초기화

초기화하면 이 브라우저에 저장된 설정과 대화가 삭제돼. 먼저 백업하는 걸 권장해.

이 앱은 현재 브라우저에 데이터를 저장해. 다른 기기나 다른 브라우저에는 자동으로 동기화되지 않아. 중요한 설정은 JSON으로 백업해 둬.
